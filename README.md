# منصتي — منصة بث مدفوعة لأفلامك ومسلسلاتك

منصة متكاملة (Next.js 14 + Prisma + Stripe) لعرض أفلامك ومسلسلاتك الأصلية باشتراك مدفوع، بواجهة عربية RTL.

## المزايا
- **واجهة مشاهدة**: رئيسية بعمل مميز وصفوف (أحدث/أفلام/مسلسلات/مجاني)، تصفّح وبحث، صفحة لكل عمل، مواسم وحلقات.
- **حماية المحتوى**: علامة مائية متحركة ببريد المشترك (تبقى في ملء الشاشة)، روابط فيديو موقّعة قصيرة العمر (10 دقائق) تتجدد تلقائيًا، وحد أجهزة متزامنة لكل حساب (`MAX_STREAMS`، افتراضيًا 2).
- **مشغّل فيديو** محمي: البث عبر `/api/stream` بعد التحقق من الاشتراك، يدعم التقديم (Range)، يحفظ موضع المشاهدة ويكمل منه، وينتقل للحلقة التالية تلقائيًا.
- **حسابات**: تسجيل ودخول بجلسات JWT في كوكي آمن، تأكيد البريد الإلكتروني، واستعادة كلمة المرور (روابط لمرة واحدة بصلاحية محدودة).
- **صفحات قانونية**: شروط الاستخدام وسياسة الخصوصية (`/terms`، `/privacy`) مع موافقة إلزامية عند التسجيل — نموذج عام راجعه مع مختص.
- **اشتراكات مدفوعة**: خطة شهرية وسنوية عبر Stripe Checkout، وبوابة إدارة الدفع، وWebhook لمزامنة الحالة (تجديد/إلغاء/تأخر).
- **محتوى مجاني اختياري**: عمل كامل أو حلقة واحدة للتجربة.
- **لوحة تحكم المدير**: إضافة/تعديل/حذف الأفلام والمسلسلات والحلقات، رفع الفيديو والصور مباشرة مع شريط تقدم (أو استخدام رابط CDN خارجي)، إحصاءات، ومنح/إلغاء الاشتراك يدويًا.

## التشغيل (Neon)
قاعدة البيانات Neon Postgres، والملفات في حاوية Neon Object Storage (`assets`) — كلاهما معرّف في `neon.ts`.
```bash
npm install
cp .env.example .env   # ثم عدّل القيم
neon login && neon deploy   # يجهّز Postgres والحاوية ويكتب DATABASE_URL و AWS_* في .env
npm run setup          # إنشاء الجداول وحساب المدير
npm run dev            # http://localhost:3000
```
ادخل بحساب المدير (`ADMIN_EMAIL`/`ADMIN_PASSWORD`) ثم افتح **لوحة التحكم** لإضافة أعمالك.

## تفعيل الدفع (Paddle — موصى به للمغرب)
1. في لوحة Paddle: أنشئ منتجًا بسعرين متكررين (شهري وسنوي) وانسخ معرّفيهما `pri_...`.
2. **Developer tools → Authentication**: أنشئ API key و Client-side token.
3. **Developer tools → Notifications**: أضف وجهة `https://نطاقك/api/paddle/webhook` بأحداث `subscription.*`، وانسخ السرّ.
4. **Checkout settings**: أضف نطاق موقعك إلى النطاقات المعتمدة.
5. عيّن متغيرات `PADDLE_*` في Vercel، ابدأ بـ `PADDLE_ENV="sandbox"` ثم `production` بعد الموافقة على حسابك.

## تفعيل الدفع الحقيقي (Stripe)
1. أنشئ منتجًا بسعرين متكررين (شهري وسنوي) في لوحة Stripe.
2. عيّن في `.env`: `STRIPE_SECRET_KEY`، `STRIPE_PRICE_MONTHLY`، `STRIPE_PRICE_YEARLY`، واجعل `PAYMENTS_DEMO="false"`.
3. أضف Webhook إلى `https://نطاقك/api/stripe/webhook` بالأحداث:
   `checkout.session.completed`، `customer.subscription.created|updated|deleted`، وضع سرّه في `STRIPE_WEBHOOK_SECRET`.
4. للتطوير المحلي: `stripe listen --forward-to localhost:3000/api/stripe/webhook`.

الأسعار المعروضة في `src/lib/plans.ts`.

> بدون مفاتيح Stripe ومع `PAYMENTS_DEMO="true"` يُفعَّل الاشتراك دون دفع — يعمل في وضع التطوير (`npm run dev`) فقط ويُعطَّل تلقائيًا في الإنتاج.

## البريد الإلكتروني
عيّن `SMTP_HOST` و`SMTP_PORT` و`SMTP_USER` و`SMTP_PASS` و`MAIL_FROM` (أي مزود: Resend، Brevo، Gmail…). عند تهيئته يُشترط تأكيد البريد قبل الاشتراك. بدونه تُطبع روابط التأكيد والاستعادة في سجل الخادم.

## ملاحظات النشر
- عند وجود `AWS_ENDPOINT_URL_S3` يرفع المتصفح الملفات مباشرة إلى حاوية Neon عبر روابط موقّعة، ويُبث الفيديو من روابط موقّعة قصيرة العمر بعد التحقق من الاشتراك. بدونه تُحفظ الملفات محليًا في `storage/`.
- يلزم أن تسمح سياسة CORS للحاوية بطلبات `PUT` من نطاق موقعك.
- على Vercel: اربط حاوية **Vercel Blob خاصة** بالمشروع (يُحقن `BLOB_READ_WRITE_TOKEN`)، فيرفع المتصفح مباشرة إليها ويُبث الفيديو من روابط موقّعة. تُستخدم حاوية Neon بدلها إن وُجدت متغيرات `AWS_*`.
- يُفضّل ترميز الفيديو MP4 (H.264/AAC) أو WebM لتوافق المتصفحات.
- غيّر `AUTH_SECRET` لقيمة عشوائية طويلة، واضبط `APP_URL` على نطاقك.
