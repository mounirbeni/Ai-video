# منصتي — منصة بث مدفوعة لأفلامك ومسلسلاتك

منصة متكاملة (Next.js 14 + Prisma + Stripe) لعرض أفلامك ومسلسلاتك الأصلية باشتراك مدفوع، بواجهة عربية RTL.

## المزايا
- **واجهة مشاهدة**: رئيسية بعمل مميز وصفوف (أحدث/أفلام/مسلسلات/مجاني)، تصفّح وبحث، صفحة لكل عمل، مواسم وحلقات.
- **مشغّل فيديو** محمي: البث عبر `/api/stream` بعد التحقق من الاشتراك، يدعم التقديم (Range)، يحفظ موضع المشاهدة ويكمل منه، وينتقل للحلقة التالية تلقائيًا.
- **حسابات**: تسجيل ودخول بجلسات JWT في كوكي آمن.
- **اشتراكات مدفوعة**: خطة شهرية وسنوية عبر Stripe Checkout، وبوابة إدارة الدفع، وWebhook لمزامنة الحالة (تجديد/إلغاء/تأخر).
- **محتوى مجاني اختياري**: عمل كامل أو حلقة واحدة للتجربة.
- **لوحة تحكم المدير**: إضافة/تعديل/حذف الأفلام والمسلسلات والحلقات، رفع الفيديو والصور مباشرة مع شريط تقدم (أو استخدام رابط CDN خارجي)، إحصاءات، ومنح/إلغاء الاشتراك يدويًا.

## التشغيل
```bash
npm install
cp .env.example .env   # ثم عدّل القيم
npm run setup          # إنشاء قاعدة البيانات وحساب المدير
npm run dev            # http://localhost:3000
```
ادخل بحساب المدير (`ADMIN_EMAIL`/`ADMIN_PASSWORD`) ثم افتح **لوحة التحكم** لإضافة أعمالك.

## تفعيل الدفع الحقيقي (Stripe)
1. أنشئ منتجًا بسعرين متكررين (شهري وسنوي) في لوحة Stripe.
2. عيّن في `.env`: `STRIPE_SECRET_KEY`، `STRIPE_PRICE_MONTHLY`، `STRIPE_PRICE_YEARLY`، واجعل `PAYMENTS_DEMO="false"`.
3. أضف Webhook إلى `https://نطاقك/api/stripe/webhook` بالأحداث:
   `checkout.session.completed`، `customer.subscription.created|updated|deleted`، وضع سرّه في `STRIPE_WEBHOOK_SECRET`.
4. للتطوير المحلي: `stripe listen --forward-to localhost:3000/api/stripe/webhook`.

الأسعار المعروضة في `src/lib/plans.ts`.

> بدون مفاتيح Stripe ومع `PAYMENTS_DEMO="true"` يُفعَّل الاشتراك دون دفع — للتجربة فقط.

## ملاحظات النشر
- الملفات المرفوعة تُحفظ في `storage/` (خارج المجلد العام) — يلزم خادم بقرص دائم (VPS/Docker). على منصات Serverless استخدم روابط CDN/تخزين سحابي في حقل الفيديو بدل الرفع المحلي.
- يُفضّل ترميز الفيديو MP4 (H.264/AAC) أو WebM لتوافق المتصفحات.
- للإنتاج بأحمال كبيرة: بدّل SQLite إلى PostgreSQL بتغيير `provider` في `prisma/schema.prisma`.
- غيّر `AUTH_SECRET` لقيمة عشوائية طويلة، واضبط `APP_URL` على نطاقك.
