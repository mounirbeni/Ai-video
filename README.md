# منصتي — منصة بث مدفوعة لأفلامك ومسلسلاتك

منصة متكاملة (Next.js 16 + Prisma + PayPal) لعرض أفلامك ومسلسلاتك الأصلية باشتراك مدفوع، بواجهة عربية وإنجليزية.

## المزايا
- **واجهة مشاهدة**: رئيسية بعمل مميز وصفوف (أحدث/أفلام/مسلسلات/مجاني)، تصفّح وبحث، صفحة لكل عمل، مواسم وحلقات.
- **حماية المحتوى**: علامة مائية متحركة باسم مستخدم المشترك (تبقى في ملء الشاشة)، روابط فيديو موقّعة قصيرة العمر (10 دقائق) تتجدد تلقائيًا، وحد أجهزة متزامنة لكل حساب حسب خطته (شهري: 1، سنوي: 2).
- **مشغّل فيديو** محمي: البث عبر `/api/stream` بعد التحقق من الاشتراك، يدعم التقديم (Range)، يحفظ موضع المشاهدة ويكمل منه، وينتقل للحلقة التالية تلقائيًا.
- **حسابات**: تسجيل ودخول بجلسات JWT في كوكي آمن، تأكيد البريد الإلكتروني، واستعادة كلمة المرور (روابط لمرة واحدة بصلاحية محدودة).
- **صفحات قانونية**: شروط الاستخدام وسياسة الخصوصية (`/terms`، `/privacy`) مع موافقة إلزامية عند التسجيل — نموذج عام راجعه مع مختص.
- **الدفع**: خطة شهرية وسنوية وتبرع حر عبر PayPal بتفعيل فوري، وأكواد تفعيل يولّدها المدير، وسجل مدفوعات في لوحة الإدارة.
- **محتوى مجاني اختياري**: عمل كامل أو حلقة واحدة للتجربة.
- **لوحة تحكم المدير**: إضافة/تعديل/حذف الأفلام والمسلسلات والحلقات، رفع الفيديو والصور مباشرة مع شريط تقدم (أو استخدام رابط CDN خارجي)، إحصاءات، ومنح/إلغاء الاشتراك يدويًا.

## التشغيل
قاعدة البيانات Neon Postgres، والملفات في حاوية Vercel Blob خاصة.
```bash
npm install
cp .env.example .env   # ثم عدّل القيم
npm run setup          # إنشاء الجداول وحساب المدير
npm run dev            # http://localhost:3000
```
ادخل بحساب المدير (`ADMIN_EMAIL`/`ADMIN_PASSWORD`) ثم افتح **لوحة التحكم** لإضافة أعمالك.

## الدفع (PayPal)
عيّن `PAYPAL_CLIENT_ID` و`PAYPAL_SECRET` (تطبيق Live من developer.paypal.com) في Vercel. بدونهما تظهر أزرار الاشتراك «قريبًا». الأسعار في `src/lib/plans.ts` و`src/lib/manual.ts`.

## البريد الإلكتروني
عيّن `SMTP_HOST` و`SMTP_PORT` و`SMTP_USER` و`SMTP_PASS` و`MAIL_FROM` (أي مزود: Resend، Brevo، Gmail…). عند تهيئته يُشترط تأكيد البريد قبل الاشتراك. بدونه تُطبع روابط التأكيد والاستعادة في سجل الخادم.

## ملاحظات النشر
- على Vercel: اربط حاوية **Vercel Blob خاصة** بالمشروع (يُحقن `BLOB_READ_WRITE_TOKEN`)، فيرفع المتصفح مباشرة إليها ويُبث الفيديو من روابط موقّعة قصيرة العمر بعد التحقق من الاشتراك. بدونها تُحفظ الملفات محليًا في `storage/`.
- ملفات الفيديو في `media-upload/` تُرفع تلقائيًا إلى الحاوية أثناء البناء (وتُتجاوز الموجودة).
- يُفضّل ترميز الفيديو MP4 (H.264/AAC) أو WebM لتوافق المتصفحات.
- غيّر `AUTH_SECRET` لقيمة عشوائية طويلة، واضبط `APP_URL` على نطاقك.
